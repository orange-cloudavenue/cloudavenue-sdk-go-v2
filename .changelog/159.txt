```release-note:feature
feat(vapp): deliver the vApp lifecycle and payload behavior verified against the live VCD 39.1 contract. Undeploy requests use the versioned VMware XML content type; DeleteVApp ignores only the explicit benign not-running undeploy case and tolerates the 404 answered by removeAllNetworks for vApps without networks; runtime network writes mutate the raw section fetched from VMware so untouched identity, features, router info and sibling network state are preserved. Guest properties round-trip with full fidelity (Key, Label, Type, Value, UserConfigurable) in stable order, with empty sections accepted and nil sections rejected. vApp job polling is configurable through the new WithJobTimeout and WithJobPollInterval client options (5-minute default timeout). Endpoints send the media types required by the API (query records JSON, instantiateVAppTemplateParams XML, productSections JSON) and instantiate/compose network payloads emit the ovf:Info and Configuration (ParentNetwork, FenceMode) blocks mandated by the VCD schema.
```
